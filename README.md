# 3 Duna — Catálogo MVP

Catálogo responsivo de peças impressas em 3D, baseado no design aprovado no Figma.

## Stack
- Nuxt 4
- Vue 3
- CSS responsivo
- Carrinho de interesse persistido em `localStorage`

## Rotas
- `/` — catálogo
- `/produto/:slug` — detalhe da peça
- `/carrinho` — lista de interesse

## Desenvolvimento
```bash
npm install
npm run dev
```

## Produção
```bash
npm run build
```
